
# News Mania - A modern news aggregation platform

News Mania is a web application that delivers real-time news across multiple categories and regions through external news APIs. Users can browse the latest headlines, explore different categories, and stay updated through a clean and responsive interface.

Built using React with API integration, dynamic rendering, state management, and responsive UI design.

- Browse latest news headlines

- Country-based news selection
- Pagination support
- Responsive interface
- Dynamic content fetched through APIs
- Loading indicators and smooth navigation

- React.js
- JavaScript

- REST APIs

## How to Run locally?

### Clone the repository

```bash
git clone <repo-url>
cd news-mania
```

### Install dependencies

```bash
npm install
```

### Configure the `.env` file

```env
REACT_APP_NEWS_API=your-api-key
```

### Run

```bash
npm start
```

### Build for production

```bash
npm run build
```

## Notes

- News content is fetched dynamically from external APIs.
- API availability may depend on regional restrictions and quota limits.
